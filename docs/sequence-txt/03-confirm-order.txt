sequenceDiagram
    title Flow 3 - Confirm Order
    actor Waiter
    participant UI as Web/Mobile UI
    participant Controller as WebApi Controller
    participant Handler as Feature Handler
    participant Repo as Repository/UoW
    participant DB as PostgreSQL
    participant Noti as INotificationService
    participant Hub as RestaurantHub

    Waiter->>UI: 1: ConfirmOrder action
    activate UI
    UI->>Controller: 1.1: HTTP PUT /api/Order/confirm
    activate Controller
    Controller->>Handler: 1.1.1: Invoke ConfirmOrderHandler
    activate Handler
    Handler->>Repo: 1.1.1.1: Execute confirm order logic
    activate Repo
    Repo->>DB: 1.1.1.1.1: Update order status + Commit
    activate DB
    DB-->>Repo: 1.1.1.1.2: DB result
    deactivate DB
    Repo-->>Handler: 1.1.1.1.3: Repository result
    deactivate Repo
    Handler->>Noti: 1.1.1.1.4: Notify chef group
    activate Noti
    Noti->>Hub: 1.1.1.1.4.1: Push realtime event
    activate Hub
    Hub-->>Noti: 1.1.1.1.4.2: Push result
    deactivate Hub
    Noti-->>Handler: 1.1.1.1.4.3: Notification result
    deactivate Noti

    alt 1.2: Order confirmed
        Handler-->>Controller: 1.2.1: Return Success(Order)
        Controller-->>UI: 1.2.2: Return ConfirmOrder success
        UI-->>Waiter: 1.2.3: Show success message
    else 1.3: Order confirmation failed
        Handler-->>Controller: 1.3.1: Return Failure(Order)
        Controller-->>UI: 1.3.2: Return ConfirmOrder failure
        UI-->>Waiter: 1.3.3: Show error message
    end

    deactivate Handler
    deactivate Controller
    deactivate UI

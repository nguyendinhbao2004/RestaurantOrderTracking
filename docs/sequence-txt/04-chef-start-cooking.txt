sequenceDiagram
    title Flow 4 - Start Cooking
    actor Chef
    participant UI as Web/Mobile UI
    participant Controller as WebApi Controller
    participant Handler as Feature Handler
    participant Repo as Repository/UoW
    participant DB as PostgreSQL

    Chef->>UI: 1: StartCooking action
    activate UI
    UI->>Controller: 1.1: HTTP PUT /api/OrderItem/start
    activate Controller
    Controller->>Handler: 1.1.1: Invoke StartCookingHandler
    activate Handler
    Handler->>Repo: 1.1.1.1: Execute start cooking logic
    activate Repo
    Repo->>DB: 1.1.1.1.1: Update order item status + Commit
    activate DB
    DB-->>Repo: 1.1.1.1.2: DB result
    deactivate DB
    Repo-->>Handler: 1.1.1.1.3: Repository result
    deactivate Repo

    alt 1.2: Cooking started
        Handler-->>Controller: 1.2.1: Return Success(OrderItem)
        Controller-->>UI: 1.2.2: Return StartCooking success
        UI-->>Chef: 1.2.3: Show success message
        Chef-->>Chef: 1.2.4: Update station board
    else 1.3: Start cooking failed
        Handler-->>Controller: 1.3.1: Return Failure(OrderItem)
        Controller-->>UI: 1.3.2: Return StartCooking failure
        UI-->>Chef: 1.3.3: Show error message
        Chef-->>Chef: 1.3.4: Retry or pick another item
    end

    deactivate Handler
    deactivate Controller
    deactivate UI

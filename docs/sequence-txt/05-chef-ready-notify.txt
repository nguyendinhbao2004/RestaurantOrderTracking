sequenceDiagram
    title Flow 5 - Mark Item Ready and Notify
    actor Chef
    actor Waiter
    participant UI as Web/Mobile UI
    participant Controller as WebApi Controller
    participant Handler as Feature Handler
    participant Repo as Repository/UoW
    participant DB as PostgreSQL
    participant Noti as INotificationService
    participant Hub as RestaurantHub

    Chef->>UI: 1: MarkItemReady action
    activate UI
    UI->>Controller: 1.1: HTTP PUT /api/OrderItem/ready
    activate Controller
    Controller->>Handler: 1.1.1: Invoke MarkItemReadyHandler
    activate Handler
    Handler->>Repo: 1.1.1.1: Execute ready item logic
    activate Repo
    Repo->>DB: 1.1.1.1.1: Update order item status + Commit
    activate DB
    DB-->>Repo: 1.1.1.1.2: DB result
    deactivate DB
    Repo-->>Handler: 1.1.1.1.3: Repository result
    deactivate Repo
    Handler->>Noti: 1.1.1.1.4: Notify waiter group
    activate Noti
    Noti->>Hub: 1.1.1.1.4.1: Push realtime event
    activate Hub
    Hub-->>Waiter: 1.1.1.1.4.2: Receive OrderItemReady event
    deactivate Hub
    Noti-->>Handler: 1.1.1.1.4.3: Notification result
    deactivate Noti

    alt 1.2: Item marked ready
        Handler-->>Controller: 1.2.1: Return Success(OrderItem)
        Controller-->>UI: 1.2.2: Return MarkItemReady success
        UI-->>Chef: 1.2.3: Show success message
        Chef-->>Chef: 1.2.4: Move dish to pass
    else 1.3: Mark item ready failed
        Handler-->>Controller: 1.3.1: Return Failure(OrderItem)
        Controller-->>UI: 1.3.2: Return MarkItemReady failure
        UI-->>Chef: 1.3.3: Show error message
        Chef-->>Chef: 1.3.4: Retry or reassign
    end

    deactivate Handler
    deactivate Controller
    deactivate UI

sequenceDiagram
    title Flow 2 - Create Order
    actor Waiter
    participant UI as Web/Mobile UI
    participant Controller as WebApi Controller
    participant Handler as Feature Handler
    participant Repo as Repository/UoW
    participant DB as PostgreSQL

    Waiter->>UI: 1: Trigger CreateOrder action
    activate UI
    UI->>Controller: 1.1: HTTP POST /api/Order
    activate Controller
    Controller->>Handler: 1.1.1: Invoke CreateOrderHandler
    activate Handler
    Handler->>Repo: 1.1.1.1: Execute create order logic
    activate Repo
    Repo->>DB: 1.1.1.1.1: Insert order/items + Commit
    activate DB
    DB-->>Repo: 1.1.1.1.2: DB result
    deactivate DB
    Repo-->>Handler: 1.1.1.1.3: Repository result
    deactivate Repo

    alt 1.2: Order created
        Handler-->>Controller: 1.2.1: Return Success(Order)
        Controller-->>UI: 1.2.2: Return CreateOrder success
        UI-->>Waiter: 1.2.3: Display success state
        Waiter-->>Waiter: 1.2.4: Continue service
    else 1.3: Order creation failed
        Handler-->>Controller: 1.3.1: Return Failure(Order)
        Controller-->>UI: 1.3.2: Return CreateOrder failure
        UI-->>Waiter: 1.3.3: Show error message
        Waiter-->>Waiter: 1.3.4: Retry or escalate
    end

    deactivate Handler
    deactivate Controller
    deactivate UI
